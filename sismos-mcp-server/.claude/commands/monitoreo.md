Usá el subagente `sismologo` para recorrer el ciclo de monitoreo:

1. Mirá qué regiones están en seguimiento
2. Traé la actividad reciente de cada una
3. Cerrá con el informe en prosa

Si la watchlist está vacía, decímelo y proponé 2-3 regiones para agregar
en vez de fallar.
