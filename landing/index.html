// el problema

    
El agente escribe rápido. La confianza no.

    

      

        
−

        
Aceptás todo el diff

        
Tab, tab, tab. Funciona en el happy path y rompe en producción un jueves a la noche.

      

      

        
−

        
No sabés qué preguntarle

        
El prompt correcto no es "hacé esto", es "hacé esto, así, por esta razón, y probalo de esta forma".

      

      

        
−

        
El agente alucina con confianza

        
Inventa APIs, ignora tests, y lo dice todo con el mismo tono seguro que cuando tiene razón.

      

    

    

      Este curso no enseña a "usar prompts mágicos". Enseña a leer un diff generado por IA
      con el mismo criterio con el que revisás el de un compañero senior —
      y a dirigir al agente para que llegue ahí directamente.

Cuatro módulos, un repo real.


    

      

        01_fundamentos/
        como_piensa_un_agente.md
        
Modelos, contexto, tokens y por qué un agente no "sabe" tu codebase — la construye en cada corrida.

      

      

        02_direccion/
        prompts_que_dan_contexto.md
        
Cómo escribir instrucciones que reducen la ambigüedad: alcance, restricciones, criterios de aceptación.

      

      

        03_revision/
        leer_un_diff_de_ia.md
        
Qué mirar primero en un PR generado por IA: efectos secundarios, tests borrados, dependencias nuevas.

      

      

        04_produccion/
        agentes_en_el_flujo_real.md
        
Integrar agentes de código a tu flujo de trabajo real: CI, revisiones de equipo, y cuándo NO delegar.

      

    

  


  
  

    
// requisitos

    
Para quién es (y para quién no)

    

      

        
Es para vos si

        
    
          
  • Ya programás profesionalmente, en cualquier stack.
    • 
          
  • Usás (o probaste) Copilot, Cursor, Claude Code o similar.
    • 
          
  • Querés soltarle tareas más grandes a un agente sin perder el control.
    • 
        

      

      

        
No es para vos si

        
    
          
  • Buscás "prompts mágicos" sin entender el código que generan.
    • 
          
  • Nunca escribiste código y esperás que la IA lo haga por vos.
    • 
          
  • Ya lideras un equipo con un flujo de agentes maduro y documentado.

// preguntas frecuentes

    
FAQ

    

      

        ¿Necesito experiencia previa con IA?
        
No. Necesitás experiencia programando. La parte de IA se enseña desde cero, con foco en criterio, no en herramientas puntuales.

      

      

        ¿Qué herramientas vamos a usar?
        
Trabajamos con coding agents de uso general (como Claude Code) para que los conceptos se transfieran sin importar qué termine usando tu equipo.

      

      

        ¿Es en vivo o grabado?
        
Encuentros en vivo online, con ejercicios sobre un repo real entre clase y clase.

      

      

        ¿Da certificado?
        
Sí, al completar los cuatro módulos y el proyecto final.
